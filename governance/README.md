# Governance — miten työtila toimii

Nämä dokumentit kuvaavat työtilan omat säännöt. Ne eivät määrittele, miten hallituksen pitäisi työskennellä — ne määrittelevät, miten hallituksen työ kirjataan.

| # | Dokumentti | Mistä |
|---|---|---|
| 01 | [Toimintamalli](01-toimintamalli.md) | Tietuetyypit, tilat ja kirjoitustasot |
| 02 | [Kokouksen valmistelu](02-kokouksen-valmistelu.md) | Esityslista, aineisto, kokousluonnos |
| 03 | [Päätökset ja pöytäkirja](03-paatokset-ja-poytakirja.md) | Rekisteri, numerointi, menettelykehys, pöytäkirjan muodostaminen |
| 04 | [Asioiden nostaminen](04-asioiden-nostaminen.md) | Miten jäsen nostaa asian kokousten välissä |
| 05 | [Lainmukaisuus ja rajat](05-lainmukaisuus-ja-rajat.md) | Osakeyhtiölain kohdat, hyväksyntätasot, normihierarkia |
| 06 | [Työjärjestys](06-tyojarjestys.md) | Runko hallituksen hyväksyttäväksi |
| 07 | [Tietosuoja ja luottamuksellisuus](07-tietosuoja-ja-luottamuksellisuus.md) | Henkilötiedot, pääsy, tekoälyn käsittely |

Sitovat agenttirajat ovat [`AGENTS.md`](../AGENTS.md):ssä. Nämä dokumentit täsmentävät niitä, eivät kumoa.
