# Kokousten välinen työ

Neljä tietuetyyppiä, yksi tiedosto per tietue. Kopioi malli, nimeä tunnuksella ja aiheella (`HAV-2026-003-nps-mittaus.md`), täytä.

| Tyyppi | Etuliite | Malli |
|---|---|---|
| Esityslistaehdotus | `ESI-` | `MALLI-esityslistaehdotus.md` |
| Havainto | `HAV-` | `MALLI-havainto.md` |
| Idea | `IDEA-` | `MALLI-idea.md` |
| Riski tai mahdollisuus | `RISKI-` / `MAHD-` | `MALLI-riski-tai-mahdollisuus.md` |

Jokainen tietue kirjaa **kuka nosti ja milloin**. Tila: `avoin` → `käsitelty` → `suljettu` (perusteluineen). Suljettua ei poisteta.

Mikään näistä ei ole päätös. Ks. [`governance/04`](../governance/04-asioiden-nostaminen.md).
