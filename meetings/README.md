# Kokousluonnokset

Kokouksen aikana kirjoitettava yhteinen luonnos. Kopioi `MALLI-kokousluonnos.md` nimelle `LUONNOS-<päivä>.md`, täytä kokouksessa, siirrä sisältö päätösrekisteriin ja **poista tai arkistoi luonnos saman päivän aikana**.

Luonnos ei ole pöytäkirja eikä päätösasiakirja. Se on valkotaulu.
